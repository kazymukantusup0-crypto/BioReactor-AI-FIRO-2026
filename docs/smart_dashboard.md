# Dashboard и агент v7.7

Из существующей папки BioReactor_AI:

    python main.py dashboard --port 8765 --no-scheduler

Откройте http://127.0.0.1:8765/dashboard/#/substrates. Если сервер уже работает, нужен перезапуск Python для обновления логики; в открытой вкладке обновите страницу.

Основные разделы — обзор, «Сырьё и смеси», чат, реактор, цены, источники. Прежние ссылки advisor, mixtures, prediction, economics, optimizer и experiments направляются в объединённый раздел. Backend и его прежние API сохранены; схема доступна на /docs.

В единой форме можно задать один или несколько материалов, количество в кг/литрах, состояние и необязательные измеренные свойства. Состав сохраняется при переходе между страницами. Для оценки используется условный литературный сценарий; предположение о сопоставимости газа явно показано и отключается в дополнительных параметрах. Неизвестные параметры не заменяются измерениями.

В чате можно последовательно написать:

1. «У меня 142 литра коровьего навоза. Сколько газа получится?»
2. «Какая температура лучше?»
3. «Сколько дней потребуется?»
4. «Добавь 20 кг пищевых отходов».
5. «А теперь сколько газа?»
6. «Что выгоднее — продать или переработать?»
7. «Объясни подробнее».
8. «Ответь одним предложением».

Вопрос о температуре не запускает рынок и экономику. Вопрос о газе не требует полного отчёта. Подробности и источники доступны по запросу. Условное добавление через «если» хранится отдельно от подтверждённого наличия и учитывается в следующем вопросе.

По умолчанию используется простой режим. Научный показывает тот же результат с происхождением данных и трассировкой, без нового расчёта. Длительность BMP не является назначенным сроком партии, а изученный режим температуры — подтверждённым оптимумом оборудования.

Qwen3 8B остаётся основной локальной моделью; qwen2.5:1.5b — резервной. При нехватке RAM защита может выбрать резерв. Простые уточнения обрабатываются без нового запроса к LLM; это штатный быстрый маршрут. В чате сохранён выбор режима без языковой модели.

CLI нового агента:

    python main.py chat --research
    python main.py chat --research --no-llm --message "У меня 100 кг коровьего навоза. Какая температура?"
    python main.py tool estimate_substrate_gas --input reports/stage7_7/focused_input.json

Проверки: python -m unittest discover -s tests -v; в frontend — npm.cmd test и npm.cmd run build. verify_stage7_7.py проверяет настоящие HTTP/Ollama/Chrome/CLI на отдельной SQLite; повтор требует нового BIOREACTOR_STAGE7_7_QA_DB. Старые проверочные базы и рабочая история не удаляются.
