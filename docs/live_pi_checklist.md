# Чек-лист: живая Pi снова доступна

Команда: «Pi подключена, пройди чек-лист».
Правила: реле **не переключать** (ни через API, ни кнопками), только смотреть, что кнопки доступны; окно
подтверждения закрывать «Отменой». Пароль Pi нигде не записывать. Сетевые настройки Pi не трогать.
Агента, расчёты и прошивку не менять. Баг в мосте или прошивке — только описать.

## 1. Связь
- [ ] Путь: `ping 192.168.50.2` (кабель) или Wi-Fi ноутбука = **BioReactor-Pi**, `ping 10.42.0.1`.
- [ ] `ssh bioreactor` (кабель) или `ssh bioreactor-wifi` (Wi-Fi) без пароля, по ключу.
- [ ] `systemctl status bioreactor-pi` → `active (running)`, без `--simulate` в строке запуска.
- [ ] Arduino: `ls /dev/ttyUSB* /dev/ttyACM*` — порт на месте.
- [ ] Мост: `curl http://<pi>:8780/health` → `"ok": true`, `"arduino_ok": true`, `"firmware": "bioreactor-1.0"`.
- Если что-то не так — остановиться и написать, что именно: нет сети / нет ssh / сервис упал / нет Arduino.

## 2. Время (синхронизация подготовлена 22.11.2026, см. docs/raspberry_setup.md, раздел 6)
- [ ] Сравнить `ssh bioreactor date +%s` с временем ноутбука.
- [ ] Задеплоить код моста: `powershell -File scripts\deploy_to_pi.ps1`.
- [ ] Новый unit (CAP_SYS_TIME): `ssh -t bioreactor "cd ~/BioReactor_AI/raspberry && sudo ./install.sh"` (без `--simulate`).
- [ ] `systemctl show bioreactor-pi -p AmbientCapabilities` → `cap_sys_time`; `/state` → `"time_settable": true`.
- [ ] Открыть дашборд: в `data/runtime/reactor_client.log` строка «Pi clock … set to the laptop's time» (если
      разница была больше 5 с), в журнале на странице «Время Pi выставлено по ноутбуку»; `date` на Pi и ноутбуке ≤ 2 с.

## 3. «Реактор» вживую (дашборд в реальном режиме, не симулятор)
- [ ] Источник на странице: «RASPBERRY PI → ARDUINO (адрес)» и маршрут (кабель / Wi-Fi Pi).
- [ ] Температура, влажность, газ внутри/снаружи приходят и меняются раз в секунду; статус связи «есть».
- [ ] Кнопки реле и автоматики активны, не серые; окно подтверждения открывается и закрывается «Отменой».
- [ ] Пороги Arduino получены; статусы «норма / внимание / авария» соответствуют текущим значениям и порогам.
- [ ] Ошибки датчиков (нет DS18B20, нет DHT, прогрев MQ) показаны словами, а не пустыми полями.
- [ ] Графики 10 мин / 1 ч рисуются; журнал команд и тревог читается.
- Уже известно по железу (18.11): DS18B20 то пропадает, то возвращается (no_temp мигает — похоже на контакт);
  газ снаружи 996–1000 при пороге 1000 даёт тревогу утечки. Это не баги интерфейса: проверить, что экран
  показывает это понятно, и записать, повторилось ли.

## 4. Обрыв и восстановление
- [ ] `ssh bioreactor "sudo systemctl stop bioreactor-pi"`, подождать 20 с: на странице «НЕТ СВЯЗИ С RASPBERRY PI»,
      все кнопки серые «Нет связи», E-STOP серый с подсказкой про BACK на Arduino.
- [ ] `ssh bioreactor "sudo systemctl start bioreactor-pi"`: без перезагрузки страницы показания вернулись,
      кнопки снова активны. Время сверено заново (лог клиента).
