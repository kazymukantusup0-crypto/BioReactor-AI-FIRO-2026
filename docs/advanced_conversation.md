BioReactor AI v8.0 продолжает существующий сервер и базы. Новая часть включается в диалогах с подстилкой, сухим навозом, независимыми состояниями и пересчётом единиц; обычные маршруты v7.7 и v5.6 сохранены. Параметр API conversation_version=7 остаётся совместимым, расширенные ответы имеют advanced_conversation_version=8.0.

Из каталога BioReactor_AI запустите `python main.py dashboard --port 8765 --no-browser --no-scheduler`, затем откройте http://127.0.0.1:8765/dashboard/. Рабочая база по умолчанию: data/market/market.sqlite3. Флаг `--no-scheduler` сохраняет проверенный режим текущего запуска; для прежнего планировщика уберите этот флаг. Обновление цен и обучение моделей при запуске v8.0 не требуются.

В разделе «Сырьё и смеси» отдельно выбираются вид животного, физическое состояние, степень разложения и подстилка. «Сухой» и «Свежий» совместимы. «Только измеренные» запрещает подстановку характеристик из литературы; «Приблизительные» разрешает применимые опубликованные свойства; «Явно условный сценарий» допускает обозначенный перенос свойств между образцами. У сухого навоза нет назначенной по умолчанию плотности. Для демонстрации её можно явно передать в properties.density_kg_l с provenance=HYPOTHETICAL_SCENARIO. Пользовательские значения имеют происхождение USER_REPORTED, без утверждения об их независимой проверке.

Объём и масса поддерживают г, кг, т, мл, л, м³. API POST /api/advisor/convert принимает объект request с компонентами AdvisorRequest и target_unit (g, kg, t, mL, L, m3). Ответ хранит диапазон, источник, ограничения и режим плотности. Пересчёт между массовыми единицами и между объёмными единицами обходится без плотности. История исходных цен, научных расчётов и чатов сохраняется.

В чате составной запрос сохраняет задачи до уточнения животного. «Коровий» возобновляет исходный расчёт. «А если 200 литров?» создаёт отдельную ветку, сохраняя исходное наличие. Добавление материала продолжает активную ветку. «Новая партия» очищает её параметры реактора и текущие задачи; прежние задачи остаются в истории. Неопределённая экономика хранится среди незавершённых задач, даже если следующий вопрос относится к температуре.

Локальная Qwen3 8B предлагает интерпретацию запроса. Числа, выбор применимого профиля и результаты инструментов проверяются Python-кодом. Дословные уточнения, форматы и известные вопросы обходятся без повторного вызова LLM. Защита от нехватки RAM и прежний резервный провайдер сохранены. Аппаратное управление выключено.

Проверки: `python -m pytest -q`, затем в frontend: `npm.cmd test` и `npm.cmd run build`. Полный независимый прогон с настоящей локальной LLM, HTTP, CLI и Chrome: `python verify_stage8_0.py`. Он использует порт 8780 и новую копию базы, записывает результаты в reports/stage8_0; предыдущие отчёты этапов не меняет. Для запуска на Windows необходимы установленный Chrome и работающая Ollama с уже выбранной Qwen3 8B.

Источники и реальные результаты приведены в [отчёте v8.0](../reports/stage8_0_advanced_conversational_ai.md). Не все категории имеют полный согласованный набор плотности, TS, VS и BMP. Численные сценарии не являются измеренной выработкой установки или интервалом с проверенным покрытием.
