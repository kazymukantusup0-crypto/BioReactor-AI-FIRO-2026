# Substrate Advisor и Mixture Builder v7.6

Работают внутри существующего FastAPI и React Dashboard. Новая база, облачная публикация и переобучение не нужны.

## Windows

Из папки `BioReactor_AI`:

```powershell
python main.py dashboard --port 8765 --no-scheduler
```

Откройте `http://127.0.0.1:8765/dashboard/#/advisor` или `#/mixtures`.
Если сервер уже запущен, используйте его окно; для загрузки нового Python-кода нужен перезапуск.
Для изменения интерфейса: `cd frontend`, `npm.cmd run build`, затем обновите страницу.
Ollama используется только для языкового разбора. Установленные qwen3:8b и резервная qwen2.5:1.5b сохранены. В чате доступен режим «Только Python»; советник и конструктор не требуют LLM.

## Возможности

* Каталог: 15 распознаваемых категорий, 3 расчётных профиля на 2 вида сырья; только один профиль содержит плотность вместе с TS/VS/BMP. Это разные показатели покрытия.
* Добавление, удаление и изменение количества компонентов. Поддерживаются кг, г, т, л и м³. Плотность не принимается равной 1 по умолчанию.
* Простое представление включено по умолчанию. Научное раскрывает тот же результат: параметры, происхождение, единицы, источники и трассировку; переключение не пересчитывает значения.
* Неполная сумма известных частей не является общим выходом смеси или его гарантированной нижней границей.
* Сравнение ограничено запасами сырья. Без модели взаимодействия, кинетики и измерений стабильности оптимальная смесь не объявляется.
* Температуры и длительности статей показаны вместе с типом опыта. Срок BMP, HRT, SRT, партия и запуск различаются. Управления оборудованием нет.

## Диалог

```text
У меня 50 кг коровьего навоза, 20 кг пищевых отходов и 10 кг травы. Что получится, если смешать?
Добавь ещё 5 кг пищевых отходов
Убери траву. Какая температура лучше?
Замени 25 кг пищевых отходов на 15 кг
Что изменится, если увеличить навоз вдвое?
```

Запрос «что если» хранится отдельно от подтверждённого состава. Для разных физических состояний или неоднозначных компонентов используйте явные `id` и полный структурированный состав.

## API

* `GET /api/advisor/catalog`
* `POST /api/advisor/analyze`
* `POST /api/advisor/compare`
* `GET /api/advisor/runs`

Пример тела `analyze`:

```json
{
  "components": [
    {"id":"c1","material":"cattle_manure","material_state":"slurry","quantity":50,"unit":"kg"},
    {"id":"c2","material":"food_waste","material_state":"prepared_pulp","quantity":20,"unit":"kg"}
  ],
  "reactor_total_volume_l":200,
  "online":false,
  "assume_common_dry_gas_basis":false,
  "objectives":["methane","energy","profit","duration","stability"]
}
```

По умолчанию API **не** считает газ разных исследований сопоставимым при неизвестной влажности. Для отдельного условного расчёта можно явно задать `assume_common_dry_gas_basis:true`; это сохраняется как допущение, а не измерение. Заведомо влажный газ автоматически не осушается. В разговорном советнике этот условный сценарий включён и помечен в результате.

Для каждого компонента можно передать `properties`: `density_kg_l`, `ts_fraction`, `vs_fraction_wet`, `vs_fraction_of_ts`, `bmp_ml_g_vs`, `carbon_fraction_wet`, `nitrogen_fraction_wet`, `gas_basis`. Доли задаются в 0–1, не процентах. Число — точечное пользовательское значение; диапазон содержит `low`, `high`, `provenance`, `evidence`. У собственного BMP нужен документированный `gas_basis` с температурой K, давлением Pa и влажностью `dry`/`wet`/`unknown`.

Для непрерывного режима органическая нагрузка требует `decision.reactor.operating_mode:"continuous"`, рабочего объёма и `feeding_period_days`. HRT вычисляется только при явных `total_daily_liquid_feed_l` и `daily_feed_includes_all_liquid:true`; это полный гидравлический поток, включая разбавление. Масса партии не считается ежедневной подачей автоматически.

`compare`: `{"base": <AdvisorRequest>, "candidates": [{"label":"Название", "components":[...]}]}`. Вариант не может превышать доступное количество компонента, менять его состояние или источник свойств. Чистая прибыль остаётся неизвестной без применимых цен, полного баланса и всех затрат. Рынок природного газа не оценивает сырой биогаз.

Подробная схема: `http://127.0.0.1:8765/docs`. Старые API сохраняются.

## CLI и проверка

```powershell
python main.py tool get_substrate_catalog
python main.py tool analyze_substrate_mixture --input reports/stage7_6/cli_input.json
python main.py chat --research --no-llm --message "У меня 20 кг травы. Какая температура?"
python -m unittest discover -s tests -v
```

Проверка настоящих HTTP/Ollama/Chrome/CLI: `python verify_stage7_6.py`. Она создаёт отдельную копию исходной SQLite, не меняет рабочие цены. Если файл проверки уже существует, задайте новый абсолютный `BIOREACTOR_STAGE7_6_QA_DB`; история предыдущих запусков не удаляется. Требуются установленный Chrome и работающая Ollama. Сетевая недоступность источников фиксируется и не заменяется вымышленными данными.

Численные профили пополняются через проверку первичного источника и отдельное рассмотрение области применимости. Автоматический Crossref-поиск добавляет только обнаруженные метаданные, без права численного использования.
