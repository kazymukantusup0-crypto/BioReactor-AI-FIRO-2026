# Design v3 — отчёт

Ветка `design-v3` (от `design-v2`; `design-v2` не тронут — запасной вариант). В `main` не слито, push не сделан
(по просьбе — только после «да»). Агент `src/agent_v10`, расчёты, API, мост Pi и прошивка не менялись.

## Стиль (по референсу «Code Theorem / Landing Page Design», только стиль)
- Фон `#0E0F0E`; карточки двух видов чередуются: светлые `#F2F2EE` (чёрный текст) и тёмные `#151615` с обводкой
  `#2A2B2A`; скругление 22 px; сетки 2×2.
- Один акцент — лайм `#B8F23A`: только фоном под чёрным текстом (плашки-заголовки, главные кнопки, ВКЛ) и формой
  в иллюстрациях; лаймовым текстом на светлом — никогда.
- Шрифты (локальные файлы, лицензии OFL рядом в `frontend/src/fonts/`): заголовки и текст — **Onest** (плотный
  гротеск с кириллицей и казахскими буквами), метки, кнопки, цифры — **IBM Plex Mono**. JetBrains Mono не взят: в нём
  нет ә ғ қ ң ұ һ.
- Кнопки — «пилюли» с ↗ (главная лаймовая); иконки и иллюстрации — свои, линейные (контур + лайм, ✦).
- Внутри светлых карточек токены переопределены на «чернильные» (текст, линии, статусы), поэтому все старые
  компоненты сами получают контраст ≥ 4.5:1 на светлом.

## Реле стенда
1 — нагрев, 2 — охлаждение (светодиоды), 3 — мешалка, 4 — компрессор. Имена в API/прошивке остались
`heat`, `cool`, `pump`, `auger` (их менять нельзя), поменялось всё, что видит человек: подписи (31 ключ × 3 языка),
иконки, иллюстрация. Тексты честно описывают текущую прошивку: в режиме АВТО Arduino сама включает **реле 3
(мешалку)**, когда газ внутри выше порога «Gas in pump»; **реле 4 (компрессор)** Arduino выключает через 10 мин
непрерывной работы; в 60 с прогрева мешалка заблокирована.

## По разделам (коммит на каждый)
| Раздел | Что сделано |
|---|---|
| Обзор | заголовок + текст + «Спросить агента ↗», справа живая линейная иллюстрация реактора на светлой карточке (пузырьки по газу; нагрев — тёплое свечение; охлаждение — синие светодиоды; мешалка вращается; компрессор гонит поток; легенда с «вкл»); 2×2 показателей; состояние системы; что умеет система |
| Реактор | показания и реле 2×2 (светлые/тёмные), свои иконки реле, ВКЛ = рамка + лаймовая плашка, без связи — все реле серые пунктирные «нет связи», E-STOP — красный |
| AI Chat | лента мышления — тёмная карточка, шаги с моно-номерами 01, 02…, пульсирующий маркер «думает»; ответ агента — светлая карточка |
| Сырьё и смеси | заголовок на плашке, ввод на тёмной карточке, результаты 2×2 светлые/тёмные |
| Остальные | заголовки на плашке, панели и метрики — карточки 22 px, метрики шахматкой |

## Что осталось / на ваше решение
- **Агент** (`src/agent_v10/tools/reactor.py`) по-прежнему говорит «откачка/насос/шнек», и его фразы-отказы
  («включи …») не знают слов «мешалка/компрессор». Агент по правилу не трогал — нужна ваша команда.
- **Сырой JSON** в «Состояние системы → Полная диагностика backend» содержит старую фразу сервера
  (`src/agent/tools.py`: «…нагревателем, насосом или клапанами»). Видимая карточка показывает новую формулировку на
  3 языках; сам сервер не менял.
- **Прошивка** по смыслу ещё старая: АВТО включает реле 3 по газу (раньше — откачка), лимит 10 мин у реле 4
  (раньше — шнек). Если на стенде это уже не нужно — это правка вашей прошивки.
- Подписи **внутри SVG-иллюстрации** масштабируются с рисунком: на ноутбуке/проекторе ~15 px, на телефоне (390 px)
  мельче 13 px.
- Проверка «Реактора» с живой Pi отложена (чек-лист `docs/live_pi_checklist.md`).
