# Два концепта «Обзора» (design-v3)

Оба работают на живых данных: симулятор двигает схему, реальный режим без Pi показывает «Нет связи».
Открыть: `http://127.0.0.1:<порт>/dashboard/?concept=a#/overview` или `?concept=b`. Концепт перекрашивает
всё приложение, а не только «Обзор». Номера приёмов — из `docs/design-v3/research.md`, раздел 3.

Общее для обоих: SVG-схема реактора (субстрат окрашен по температуре: холодный — синий, прохладный — зелёный,
рабочие 35–38 °C — тёплый янтарный; пузырьки по газу; колокол газгольдера поднимается с газом; нагрев,
охлаждение, насос, шнек светятся и двигаются только когда реле включено); при обрыве связи схема серая,
неподвижная и с плашкой «Нет связи». Метан — тот же расчёт, что на «Сырьё и смеси», для демо-реактора 160 л.
Проверено: 3 языка, текст ≥ 13 px, контраст ≥ 4.5:1, ~144 кадра/с (упирается в частоту экрана).

## A — «Ночной чертёж»
Файлы: `concept-a-ru.png`, `-kk`, `-en`, `-ru-full`, `-nolink-ru`.
Тёмно-синий лист с тонкой инженерной сеткой, бочка в разрезе с размерными линиями («200 л», «рабочий 160 л»)
и выносками датчиков, рядом газгольдер. Справа стеклянная панель приборов: дуга температуры с зелёным
коридором нормы и отметкой перегрева, дуга газа с отметкой порога откачки, крупная цифра метана.
Акцент — голубой цвет газа, тепло — янтарь.
Приёмы: 1 (реактор — герой), 4 (цвет только у отклонений), 5 (шкала с зоной нормы), 6 (цвет по физике),
8 (свежесть данных и «Нет связи»), 11 (сетка оправдана чертежом), 12 (стекло только поверх светящейся схемы).
Характер: точный, «лабораторный прибор»; сильнее выглядит у жюри-инженеров.

## B — «Живой процесс»
Файлы: `concept-b-ru.png`, `-kk`, `-en`, `-ru-full`, `-nolink-ru`.
Тёплый тёмный «почвенный» фон с мягким светом и лёгким шумом. Весь процесс одной линией слева направо:
сырьё → шнек → реактор → насос → газгольдер → горелка (пламя зажигается, когда идёт газ).
Под схемой — три огромные цифры шрифтом Geologica (температура окрашена цветом субстрата).
Без приборных дуг: цифры сами — главный элемент.
Приёмы: 1, 2 (поток с импульсами только при работе насоса), 6, 7 (включённое светится), 9 (крупная цифра +
слово-вывод), 13 (одно появление «наполнение реактора»), 14 (читается с другого конца зала).
Характер: понятнее фермеру и эффектнее на проекторе издалека; меньше «инженерных» деталей.
