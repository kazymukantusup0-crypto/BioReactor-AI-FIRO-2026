# Design v2 — отчёт

Ветка `design-v2` (от `reactor-hardware`), в `main` не слита. Менялся только внешний вид:
вне `frontend/` и `docs/` изменений нет; `reactorApi.ts`, `agentV10.ts`, `api.ts`, агент `src/agent_v10`, расчёты и логика реактора не тронуты.

## Выбор
Тема **B «Приборная панель»**: графит + лайм; шрифт **Golos Text**, показания — **IBM Plex Mono** (tabular-nums).
Шрифты — локальные woff2 в `frontend/src/fonts/` (OFL, кириллица с казахскими буквами и ₸, 28 файлов, 254 КБ), без CDN.

## Что сделано (по коммитам)
1. **P1 Реактор без связи**: кнопки серые, пунктир, иконка-вилка, подпись «Нет связи»; состояние реле «нет связи»; E-STOP серый с подсказкой «жмите BACK на Arduino 2 с». Неактивная кнопка нигде больше не залита акцентом и не гасится opacity.
2. **Токены**: ~150 цветов в CSS и 27 в TSX → токены `design.css :root`; графики берут цвета через `src/theme.ts`.
   Статусы отдельными токенами: `--ok` (норма, зелёный), `--warn` (внимание), `--danger` (авария), `--offline` (нет связи, серый + пунктир). Цвет никогда не единственный признак: иконка или слово.
   Тест-сторож `tests/design-tokens.test.ts`: новый зашитый цвет или шрифт из интернета роняет vitest.
3. **Тема B + шрифты**, токены движения (ease-out, 150/200/250 мс), выделение текста и скроллбары в цветах темы.
4. **Обзор**: две сетки одинаковых карточек → одна «приборная панель» статусов (иконка ✓/⚠/✕ у каждого) + список 2×2 без рамок; подвал ≥ 4.5:1.
5. **AI Chat**: лента мышления — иконки lucide вместо 12 эмодзи; вопрос агента в тонированной рамке; без боковых полос; новое сообщение 250 мс, строки ленты 200 мс.
6. **Реактор**: полоски с анимацией `width` (мёртвый код) удалены; переключение реле — смена цвета 200 мс; окно подтверждения fade + scale(.96) 200 мс.
7. **Сырьё и смеси**, **остальные**: серые неактивные кнопки (правило advisor.css и глобальное opacity .5 перебивали систему), рамки вместо боковых полос, без полосы у активного пункта меню.

Анимации (Emil): только transform/opacity/цвет, 150–250 мс, нажатие кнопки scale(.97), hover только для мыши.
`prefers-reduced-motion`: движение убрано, остаются цвет и fade; состояние реле меняется мгновенно.
