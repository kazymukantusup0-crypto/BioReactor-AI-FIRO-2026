# FIRO Demo MVP — реализован и проверен

**Три ограниченных демонстрационных сценария работают в браузере без модели и с настоящей Qwen3 4B. Общий статус проекта FIRO READY не объявляется.** Записанные телеметрические временные метки сохраняют фактическое время исполнения; отчёт текущей пользовательской сессии — 12 ноября 2026.

## Реализованные функции

Экспериментальный флаг `--firo-demo`, отдельная SQLite-база, три запускаемые карточки на существующей странице Demo. Расчёт/ограничения выполняются детерминированно до запроса LLM. Используются прежние `explicit_calculations`, typed dialogue extraction/state, `assess_dialogue_state`, `render_capacity_notice`, каталог научных источников, arithmetic/scientific/numeric verifiers. Нового BMP-алгоритма или обучения нет.

Qwen получает готовый проверенный ответ и результаты, а её пояснение проходит существующие проверки. На один сценарий максимум один вызов модели; цикл самокорректирования не выполняется. Если пояснение не прошло проверку или модель недоступна, основной ответ и данные остаются видимыми. Отдельные блоки интерфейса показывают входы, Python-результаты, научную проверку, неизвестные параметры, источники и статус пояснения.

Результаты и диагностика сохраняются в `data/runtime/firo_demo.sqlite3`; браузер хранит ID последнего результата. Проверено восстановление после reload и чтение всех трёх реальных результатов после перезапуска экспериментального backend. Есть отмена, доставка cancellation signal в provider и защита от позднего сохранения пояснения; её проверка в этой работе детерминированная, отдельного live-cancel не проводили.

## Реальные браузерные результаты

Chrome запускался через установленный `playwright-core`, тесты нажимали реальные кнопки и вызывали живой FastAPI на `127.0.0.1:8770`. Моки HTTP и fake provider не применялись. Каждый принятый ответ Qwen сохранён вместе с метриками Ollama, черновиком, проверками и телеметрией.

| Сценарий MVP | Без модели | С Qwen в Chrome | Результат |
|---|---|---|---|
| A — 0,6 кг VS × 250 мл CH₄/г VS | PASS | PASS | Python вернул 150 л CH₄. Qwen повторила подтверждённые значения и объяснила, что выход за 30 дней не определён. Числа прошли проверку с сохранением происхождения и единиц. |
| B — 142 л навоза / номинальные 200 л реактора | PASS | PASS после исправления ролей | Масса, VS, BMP и выход остаются неизвестными; рабочий объём не принят равным номинальному. Есть конкретные вопросы о массе/плотности и рабочем объёме. Qwen пояснила недостаток данных. |
| C — анаэробность | PASS | PASS | Основной ответ по источникам содержит разные пути, включая CO₂/H₂, и отсутствие потребности в свободном кислороде. Qwen объяснила анаэробность без утверждения общего единственного пути. |

Исходные ответы модели:

* A: «Потенциал метана рассчитан как 150 л CH₄ при 0,6 кг VS и BMP 250 мл CH₄/г VS. Выход за 30 дней не определён, зависит от условий и кинетики реакции.»
* B: «Для прогноза метана из 142 л коровьего навоза в реакторе объемом 200 л недостаточно данных: масса, VS, BMP, кинетика и условия. Недостающие параметры: масса сырья, VS, BMP, рабочий объем, кинетика. Без этих данных точный расчет метана невозможен.»
* C: «Анаэробное сбраживание проводится без кислорода. Метаногены используют разные пути для образования метана, не требуя кислорода. Разные виды метаногенов применяют разные механизмы, не все из которых одинаковые.»

Независимая оценка: для ограниченных демонстрационных вопросов утверждения допустимы. B и C стилистически повторяются; перечисление конкретных путей в C обеспечивается основным ответом из источников, а не Qwen. Это не проверка всех возможных биологических вопросов.

## Ресурсы и промежуточные проблемы

Первоначальная попытка с Qwen заблокирована при 5345,4 MiB свободной RAM; основной ответ остался на экране. После сообщения пользователя об освобождении памяти выполнены последовательные реальные запросы. Входной порог 6656 MiB, runtime floor и GPU/commit/VRAM-защиты не менялись.

| Сценарий | RAM до / минимум / после, MiB | min commit headroom, MiB | max VRAM, MiB | max GPU °C | LLM время, с |
|---|---:|---:|---:|---:|---:|
| A | 6992,4 / 6082,6 / 6999,1 | 16902,2 | 3959 | 65 | 3,323 |
| B ретест | 7076,6 / 6186,8 / 7075,5 | 16980,2 | 3962 | 67 | 3,747 |
| C | 6891,6 / 6094,2 / 7006,0 | 16870,8 | 3983 | 69 | 5,421 |

Это дискретные снимки, не доказанные абсолютные пики. После каждой генерации модель адресно выгружалась за 0,160–0,165 с, список моделей в телеметрии пуст. Итоговая команда `ollama ps` также вернула пустую таблицу.

Первое пояснение B отклонено из-за ложного отнесения «142 л коровьего навоза» и обратного порядка «реакторе объёмом 200 л» к метану. Исправлена существующая `quantities9.py`: прилагательное перед материалом и обратный порядок объёма сосуда сохраняют физическую роль. Добавлена регрессия, сохранившая запрет подмены сырья метаном. Первый ответ сохранён в [qwen_B_pre_roles.json](firo_demo_mvp/qwen_B_pre_roles.json), затем повторён только B и принят.

## Проверки и команды

```powershell
python -X utf8 -m pytest -q tests/test_firo_demo_mvp.py tests/test_dashboard.py tests/test_qwen4b_manual_chat.py tests/test_numeric_claim_origins.py tests/test_live_ae_response_integrity.py --basetemp=tmp_firo_mvp_postbuild -p no:cacheprovider
```

**91 passed**, одно предупреждение Starlette. Проверки включают опциональный режим, сохранение/восстановление, неизвестные параметры, недоступный provider, отмену/поздний результат, неверные численные утверждения и существующий Dashboard.

```powershell
npm.cmd run build
npm.cmd test -- --configLoader runner
node tests/firo-demo-mvp-browser.mjs
node tests/firo-demo-mvp-browser.mjs --with-qwen
node tests/firo-demo-mvp-browser.mjs --with-qwen --live-case=B
```

Frontend build PASSED; **80 frontend tests passed**, 11 файлов. В этой ограниченной среде обычный `npm test` не загрузил bundler config из-за доступа к родительской директории; штатный `--configLoader runner` прошёл. Один промежуточный backend-прогон застал удалённый на время сборки `dist` и дал 404 для static route; после окончания сборки полный целевой набор повторён и все 91 проверки прошли. Не считать эти промежуточные ошибки успешными проверками.

## Ограничения

Проверены три фиксированных сценария, не общий свободный научный диалог. Нет live-датчиков, команд оборудованию, подтверждённого выхода за срок, независимого holdout или полного acceptance всех функций. Cancellation проверена детерминированно; отдельное новое реальное прерывание генерации в MVP не испытывали. Отсутствующая LLM не мешает основной демонстрации. **MVP реализован и проверен в браузере; готовность всего BioReactor AI к FIRO не заявляется.**
