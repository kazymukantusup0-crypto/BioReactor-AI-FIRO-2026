# v7.6 — аудит и изменения

Исходное состояние: 274 backend-теста, v7.5 decision_analysis, проверенный RM1, 28 цен, разговорная память, 2 сессии/10 сообщений на момент снимка. Файлы моделей, научные профили, старые отчёты и строки SQLite сохранены до изменений. Старые калькуляторы и API остаются.

Обнаружено: единичная грамматика количества не хранит отдельные компоненты; отсутствует самостоятельный расчёт смеси, этапность проверки новых публикаций и разделение длительности BMP/HRT/batch/startup в рекомендациях. Режимы отображения пока показывают технические статусы обычному пользователю.

План файлов:
* src/advisor/schemas.py, catalog.py, mixing.py — отдельные количества/единицы, научные свойства и условная аддитивная оценка.
* temperature.py, duration.py, optimization.py — условия применимости, HRT/SRT/BMP/batch, сравнение без выдуманной синергии.
* src/research/advisor_pipeline.py — этапы проверки и тематический Crossref-поиск с существующим кешем/ограничениями.
* src/agent/mixture_parser.py, advisor_bridge.py, human_response.py — инвентарь смеси, редактирование, отдельные гипотезы, RU/KK/EN.
* src/advisor/api.py — добавочные API для одиночного сырья/смесей/сравнения.
* React Substrate Advisor, Mixture Builder, Process Recommendations/Comparison и общий Simple/Scientific переключатель; старые разделы остаются.
* Unit/HTTP/Chrome/Ollama/CLI-проверки A–F и сохранности, reports/stage7_6_substrate_advisor.md.

Реальные источники: RM1 неизменен; Baek et al. 2020 (10.3390/ijerph17134737) — характеристики трёх субстратов и опубликованная модель лабораторной смеси, не универсальный коэффициент синергии. Moset et al. 2015 (10.1111/1751-7915.12271) — 35/50 °C и HRT 16/20 суток для конкретных CSTR. Ulukardesler 2023 (10.1038/s41598-023-33169-0) — опыт трава/навоз/инокулят, batch 65 суток, не отдельный BMP травы. Свежесть/форма/метод и неизвестные поля сохраняются явно.

Если вид навозной жижи не указан, КРС не становится подтверждённым фактом: возможен только отдельно помеченный пример для КРС с вопросом о виде. Сумма известных частей при неполных данных не выдаётся за общий выход смеси.
