# BioReactor AI — помощник для маленькой биогазовой установки

Фермер пишет как удобно — «5 вёдер навоза», «бочка не утеплена, на улице −15», по-русски, по-казахски или по-английски. Агент считает, сколько будет газа, сколько энергии уйдёт на подогрев, какой режим ставить и что выгоднее. Работает **локально, без интернета**: модель qwen3:8b через Ollama на ноутбуке.

**Главный принцип: все числа и выводы считает Python, модель только выбирает расчёт и пересказывает результат.** Каждое число в тексте модели сверяется с расчётом, каждый вывод («газа не хватит», «баланс в минусе») — с решением Python. Если текст расходится с расчётом, модель переписывает его, а при повторной ошибке ответ собирается по шаблону.

## Запуск

Двойной клик по **`ЗАПУСК_BioReactor.bat`**. Он проверяет Python-окружение, запускает Ollama и прогревает модель, при необходимости собирает интерфейс и открывает чат: http://127.0.0.1:8765/dashboard/#/chat

Нужно один раз: Windows, [Python 3.13](https://python.org), [Ollama](https://ollama.com) + `ollama pull qwen3:8b`, [Node.js LTS](https://nodejs.org) (только для первой сборки интерфейса). Без Ollama всё тоже работает: те же расчёты и выводы, текст по шаблону.

## Как агент отвечает

1. **Факты** — Python разбирает текст: сырьё, единицы («ведро = 10 л», «мешок ≈ 50 л» — с пометкой «допущение»), температура, утепление, объём реактора.
2. **Выбор** — модель выбирает один из 7 инструментов (не больше 5 шагов).
3. **Расчёт** — Python: метан = VS × BMP; энергия = CH₄ × 9,97 кВт·ч/м³; подогрев = m·c·ΔT + UA·ΔT·t (U бочки 5,4–11,2, с пенополистиролом 50 мм 0,62–0,75 Вт/(м²·К)); данные из литературы с источниками.
4. **Выводы и совет** — Python решает: какой режим, плюс или минус энергобаланс, хватит ли газа, поместится ли партия, что выгоднее. Если баланс в минусе — сам считает совет (утепление 50 мм / 35 °C) «было → стало».
5. **Ответ** — модель пишет 2–4 предложения: сначала «≈ значение», потом диапазон; проверка чисел и выводов.

Всё это видно в чате: «лента мышления», а в **режиме жюри** — каждый шаг с аргументами и временем, плюс кнопки готовых сценариев.

## Демо-реактор

Если пользователь не назвал параметры, берутся значения демо-реактора из **`data/config/demo_reactor.json`**: пластиковая бочка 200 л, рабочий объём 160 л, без утепления, жидкий навоз КРС, +5 °C. Каждое такое значение показывается в «Допущениях». Чтобы подставить свой реактор, достаточно поменять числа в файле.
